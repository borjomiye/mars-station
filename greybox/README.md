# Greybox: исходный прототип механик (архив)

`greybox.html` — прототип одним файлом (чистый JS + Canvas), с которого перенесена механика игры. Открывается двойным кликом, без сборки.

**Источник правды теперь `src/engine/`.** Этот файл оставлен как быстрый стенд и для истории; новые правила и числа вносите в `src/engine` и `src/data/balance.json`, а не сюда.

Окно DONKI внутри этого файла (сентябрь 2017) записано по памяти и помечено `verified: false`. В самой игре используются реальные данные из `src/data/donki-periods.json`.
