# Графика Mars Outpost (`src/assets/`)

Пиксель-арт игры. Владелец папки — P6 (графика и UX). Что получилось вместе, смотри в `preview-board.jpg`: поле станции, экипаж по комнатам, лаборатория без энергии затемнена.

Вся графика нарисована командой в Google Flow (ИИ-генерация) и обработана вручную. Это **не** снимки NASA: на экране «Откуда данные» так и пишем. Исключение — `cards/`: настоящие фото NASA для карточек альбома (подобрал P4, автор снимка указан в `src/data/cards.json`).

## Папки

| Папка | Что внутри | Формат |
|---|---|---|
| `station/` | поле станции: `module-left`, `dome`, `module-right`, готовая сборка `station-board.png` (1600×448), солнечные панели (чистая и в пыли), раскладка `board.json` | PNG, прозрачный фон |
| `crew/` | экипаж в полный рост (`leo`, `mei`, `amara`, `otto`, `sam`), они же в скафандрах (`suit-*`), портреты (`portrait-*`) | PNG, прозрачный фон |
| `robot/` | робот-помощник: `robot-wave`, `robot-point`, `robot-tablet` и лица `face-calm/happy/worried/alert/thinking` | PNG, прозрачный фон |
| `icons/` | иконки до 128 px: ресурсы, погода, ячейки, значки дозы, состояния экипажа, радио и т. д. | PNG, прозрачный фон |
| `patch/` | нашивка миссии: рамки `border-circle/shield/hexagon/square` (внутри прозрачные, цвет ткани подкладываем в CSS под рамку) и эмблемы `emblem-rocket/sprout/rover/otter`, которые ставятся в центр | PNG, прозрачный фон |
| `scenes/` | фоны и картинки событий, 1280×714 | JPG |
| `cards/` | настоящие фото NASA для альбома, `<id карточки>.jpg`, 640 px (images.nasa.gov) | JPG |

## Поле станции: `station/board.json`

Все координаты в пикселях поля (1600×448, как `station-board.png`). Если поле масштабируется, всё умножаем на один и тот же коэффициент.

- `rooms.<id>`: окно комнаты `x, y, w, h`, система движка `system`, точка для подписи и гнёзд ячеек `label`, две точки `slots`, куда ставятся ноги человека (якорь снизу по центру).
- `crewHeight`: рост человека на поле (116 px при ширине 1600).
- `layers` + `layerOrder`: если нужно рисовать части по отдельности (например, затемнять одну). Купол рисуется последним, он закрывает торцы модулей.

| Комната | `id` | Система движка | Кто там по умолчанию |
|---|---|---|---|
| Лаборатория | `lab` | `lab` | Otto, учёный |
| Медпункт и укрытие | `medbay` | `shield` | Mei, медик |
| Теплица (купол) | `greenhouse` | `greenhouse` | Amara, ботаник |
| Мастерская с насосом | `workshop` | `life` | Leo, инженер |
| Радиорубка | `radio` | `radio` | Sam, пилот |

Комната без энергии: тёмный прямоугольник поверх `rooms.<id>` (например, `rgba(10,12,20,.7)`), отдельной картинки нет.

## Сцены: какое событие какой картинкой

| Файл | Где |
|---|---|
| `bg-clear`, `bg-dust-storm` | фон за полем станции: ясно / пыльная буря |
| `scene-station` | старт, тихий сол |
| `scene-dust-storm` | событие `dust_storm` |
| `scene-radiation-storm` | событие `solar_storm` |
| `scene-hull-crack` | `hull_crack` |
| `scene-antenna-off` | `antenna_off` |
| `scene-breakdown` | `pump_broken`, `loose_pipe`, `power_fault` |
| `scene-medbay-1`, `scene-medbay-2` | `sick_crew`, один или двое в медпункте |
| `scene-striped-rock` | шанс `striped_rock` |
| `scene-frost` | шанс `dawn_frost` |
| `scene-dust-devil` | шансы `dust_devil` и `clean_wind` |
| `scene-blue-sunset` | шанс `blue_sunset` |
| `scene-interior` | промотка солов / вид изнутри |
| `scene-victory`, `scene-failure` | отчёт: корабль домой / досрочный возврат |

Лампы в теплице (`lamp_fault`) показываем прямо на поле: купол темнее и мигает.

## Чего здесь нет

- Анимаций (покачивание экипажа, лампочки, тарелка, пыль) — делаются в CSS.
- Рамки карточки альбома — в CSS.
- Фото NASA для карточек альбома.
- Логотипа: ждёт названия игры.

## Мелочи, о которых стоит знать

- Спрайты уменьшены со сглаживанием. Показывать их в размере экспорта или мельче; не растягивать и не ставить `image-rendering: pixelated`, иначе края станут ступеньками.
- У правого модуля под куполом спрятан люк. Виден только его край у стыка с куполом, он читается как стыковочное кольцо.
